## Rights and provenance

Original CC BY 4.0 paper licenses remain unchanged where stated. Some source manuscripts also identify separate MIT licensing for their reproducibility code; those code rights are not altered by these document copies. The source ZeroThink architecture manuscript has no explicit license statement, so this preservation does not invent or replace a grant for it. All original copyrights, attribution and disclosures remain in the documents. This folder is not covered by the separate ZMath application's noncommercial software license.

[SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) records source-relative paths, hashes, sizes, titles, author, public Markdown mappings and original license statements. No private absolute source paths are recorded. Duplicate release-package copies and three already-published PDF/DOCX editions were not copied.

## Bounded checks

All 11 complete PDF texts, 11 DOCX texts and their metadata/relationships were inspected with token/private-key/credential-link shape checks: zero hits. No DOCX embedded documents were found. Normalized five-word text overlap with the public source manuscripts was approximately 95–98%; this is a consistency signal, not exact textual identity or a scientific validation.

Poppler rendered all first and last PDF pages plus three intermediate pages (25 pages). Nine representative pages were visually inspected: Bio-Inspired Recursive Computation 1 and 4; ZME1 1, 3 and 9; ZeroThink Architecture 1 and 9; OpenZero Runtime 3; Protected Communications 3. These include title/author pages, final pages, a source-hash table and a benchmark table. Inspected pages were legible without observed clipping, overlap or broken table cells. Original justified-text spacing and page layout were preserved. This is bounded preservation QA, not a claim that every page received visual review.

PDFs were copied without authoring, modification or re-export. DOCX files were copied without Word re-saving. All copied hashes were verified against their original files.
