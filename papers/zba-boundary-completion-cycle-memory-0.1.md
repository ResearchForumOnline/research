# Boundary Completion and Cycle Memory in Zero Boundary Algebra

**Shafaet Brady Hussain** · Working research draft 0.1 · 27 September 2026

[Download/read the original 17-page PDF](ZBA_368_Boundary_Completion_and_Cycle_Memory.pdf)

This paper specifies a phase-only guarded-transition model for ZBA and separates endpoint transformations from retained cycle history. It develops matrix-algebra dimension results, a polynomial representation for a directed cycle, policy conditions for reset/mirror commutation, and a bound on how many distinct operation histories can collapse to the same structural transformation. It includes proofs, independent executable-check results, a source-scope record, and references.

The paper describes matrix, path, Iwahori, Lie, and SU(3) representation structures as established mathematics. Its claims are conditional on the models it defines. The author explicitly says the literature search was targeted rather than exhaustive and does not claim a new physical law, a cryptographic primitive, or historical priority for an eight-dimensional boundary algebra. See the PDF for complete assumptions, theorems, limits, code instructions, and references.
