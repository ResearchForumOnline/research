# Research and security scope

This package is a local research reference. It has no network client, account
integration, credential lookup, external submission command or product runtime.
Its simulator caps widths at 12 qubits and circuits at 4,096 operations. These
limits bound the reference simulation; they do not make arbitrary Python code
safe to execute. Inspect downloaded source before running it.

No encryption, key generation, entropy generation, password protection, medical
interpretation or security-strength improvement is implemented or claimed.
Record software issues through the public repository without attaching personal
records, real secrets or private research output.
