# Dependencies and licenses

Python 3.10 or later is required. The implementation and tests use only Python's
standard library: argparse, cmath, collections, copy, fractions, hashlib, json,
math, pathlib, sys, unittest and unittest.mock. No external Python package,
model, provider SDK, network service or database is needed or vendored.
