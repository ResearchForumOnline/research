# Changelog

## 1.0.0 - 23 October 2026

First public provider-neutral subset. Generic offline helper functions were
selected from earlier internal research and assigned this new ORP-001 protocol.
The four-qubit, ten-circuit manifest and all published fixtures were newly
created and generated locally. Resource and input-validation guards were added.
Seventeen independent software checks cover mapping, analytic distributions,
mutation rejection, invalid data and execution with network access disabled.
This release is distinct from any earlier frozen private-study manifest and
contains zero copies of its historical service results.
