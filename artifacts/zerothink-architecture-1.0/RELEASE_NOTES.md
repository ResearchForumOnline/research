# ZeroThink 1.0 release notes

This release consolidates the ZeroThink architecture around an evidence-gated request lifecycle and replaces broad intelligence or quantum claims with testable service boundaries.

Included:

- publication-quality Markdown, PDF, and DOCX manuscript;
- dated public-boundary and authenticated-routing evidence already held in `data/benchmarks/`;
- machine-readable trace schema;
- dependency-free conformance verifier;
- six positive and negative test vectors with a recorded 6/6 expectation match;
- citation metadata, checksums, limitations, and AI-use disclosure.

The paper is an author-led preprint and self-evaluation. The executable suite checks a narrow set of invariants only. It does not establish peer review, independent validation, factual correctness, security certification, quantum computation, or superiority over a frozen baseline.
