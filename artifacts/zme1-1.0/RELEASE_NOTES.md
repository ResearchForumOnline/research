# ZMath Shield and ZME1 1.0 release notes

This release consolidates the ZME1 public container family around standard primitives and explicit evidence boundaries.

Included are a nine-page preprint in Markdown, PDF, and DOCX; exact frozen-source hashes; two recorded public regression-program passes; a machine-readable structural schema; four structural positive/negative expectations with 4/4 matches; limitations; and an AI-use disclosure.

This is an author-led preprint and self-evaluation. It does not claim a new base cipher, quantum security, quantum-hardware provenance, cryptographic certification, production readiness, peer review, or independent validation. Private ZMath key-management and policy-service code is not released.
