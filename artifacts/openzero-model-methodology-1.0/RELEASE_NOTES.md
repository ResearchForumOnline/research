# OpenZero Model and Dataset Methodology 1.0

This working-paper release documents a deterministic, rights-bounded methodology for private OpenZero model experiments. It includes public-safe corpus hashes and counts, prompt-group split logic, QLoRA and distillation boundaries, promotion gates, a verifier, PDF, DOCX, Markdown, and an evidence manifest.

Dataset rows, teacher outputs, locked evaluations, adapter weights, and model weights are excluded. No successful full training, capability improvement, safety certification, public derivative model, peer review, or independent validation is claimed.
