# OpenZero local-first agent runtime 1.0

This release consolidates OpenZero as an integration runtime with declared local, network, model, wrapper, tool, integrity, and offline boundaries.

Evidence includes 6/6 Python compilation checks, a public 11-route historical benchmark, exact source hashes, and a companion verifying eight action classes plus fail-closed unknown actions. No runtime, doctor, tool, cloud provider, remote host, model download, or installer was executed for this paper.

This author-led preprint does not claim general model superiority, complete offline operation, universal privacy, safe autonomy, production security, peer review, or independent validation.
