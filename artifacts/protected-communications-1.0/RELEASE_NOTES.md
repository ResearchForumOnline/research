# Zmail and CallChat protected communications 1.0

This release consolidates protected email, Matrix messaging, portable-object, device-profile, and call-media layers without conflating their trust boundaries.

Evidence includes 12/12 targeted Zmail/ZMath tests, two passing CallChat profile/interception programs, six reported media-verifier contracts, exact snapshot hashes, a layer model, and negative claim boundaries. The media verifier was local and did not run optional live-parity checks.

This author-led preprint does not claim universal E2EE email, AES-512, quantum encryption, post-quantum security, endpoint security, certification, peer review, or independent validation.
