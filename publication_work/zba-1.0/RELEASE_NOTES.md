# Zero Boundary Algebra 1.0 public preprint

This release contains the first consolidated formal specification of Zero Boundary Algebra by Shafaet Brady Hussain.

## Included

- source manuscript in Markdown;
- publication PDF and editable DOCX;
- JSON Schema for the minimum evidence record;
- citation metadata;
- SHA-256 digest manifest.

## Scientific boundary

ZBA is released as an algebraic control and provenance framework under formal development. The paper does not claim peer review, independent validation, cryptographic strength from notation, quantum key distribution, quantum encryption, legal ownership by publication alone, or institutional endorsement.

## Public/private boundary

No private ZMath implementation code, keys, prompts, customer data, private evaluation material, or live-system internals are included.
